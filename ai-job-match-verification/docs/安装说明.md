# 让 Agent 帮你安装

准备一个支持 Agent Skills、能读取文件和执行脚本的 Agent。搜索岗位还需要联网搜索／浏览能力。

## 方法一：把 GitHub 链接发给 Agent

复制下面这段，把占位内容替换为实际仓库链接：

> 请从https://github.com/leiart5525/ai-job-match-verification安装 ai-job-match-verification Skill。先检查仓库内容，再把 skills/ai-job-match-verification 完整安装到当前工具支持的技能目录；不要覆盖已有同名安装。检查必需运行环境，按需配置简历解析与 Excel 导出依赖，并告诉我哪些能力已验证可用。安装后告诉我是否需要重新加载，以及如何开始使用。

本项目仓库地址已填入；安装需要仓库中已上传完整源码。无需自己先记住安装命令；具体安装位置由 Agent 根据你使用的工具确定。

## 方法二：直接使用下载包

解压发布包，将整个项目文件夹提供给 Agent，再发送：

> 请安装这个项目里的 ai-job-match-verification Skill。先读 README 和 Skill 内容，把 skills/ai-job-match-verification 完整安装到当前工具支持的技能目录，不要覆盖已有同名安装。检查依赖并做安装验证，然后告诉我如何开始使用。

如果当前工具不能读取本地文件夹，请提供它能访问的仓库链接。安装后按 Agent 提示重新加载或开启新对话。

## 开始使用

> 使用 ai-job-match-verification 帮我找工作。我之前做策略增长运营，主要考虑上海。

Skill 会复用你已提供的信息，补问缺少的岗位方向、地点、工作年限或最高学历，并同时列出可选补充项。你可以上传简历，也可以直接对话介绍经历。

## Agent 安装时需要检查什么

- 基础脚本需要 Python 3.10+；搜索和语义分析由宿主 Agent 完成。
- PDF／Word 解析、Excel 导入按需安装依赖；扫描简历还需要 OCR。
- 自带 Excel 导出器需要 Node.js 和可用的 `@oai/artifact-tool`。本项目已在提供该运行时的环境验证，其他环境不能保证可获得相同依赖；安装完成不等于 Excel 导出已可用，需实际检查并说明。
- 简历、搜索状态和投递记录保存在私人工作目录，不放入 Skill 安装目录或公开仓库。

开发者手动安装和运行命令见 [README](../README.md)。
