# 用中文对话，找到值得进一步了解的岗位

AI Job Match & Verification 帮你发现岗位、核对招聘来源、对照经历，并维护投递记录。你可以直接用中文描述需求，不必先填一份长问卷。

> 以下是功能演示，不是真实搜索记录。人物经历、公司和岗位均为虚构；示例不提供招聘链接，也不代表任何公司正在招聘。实际使用会展示观察到的真实链接、核验时间和访问限制。

## 1. 从一句话开始

**用户：**

> 我之前做策略增长运营，想找上海最近在招的岗位。

**Agent：**

> 可以。我先按“策略运营、用户增长运营”这个范围理解；如果你想转其他方向，也可以告诉我。
>
> 还需要补充两项：你有几年工作经验？最高学历是什么？
>
> 也欢迎一起补充期望薪资、偏好行业或公司、擅长的技能和项目成果、到岗时间；方便的话可以上传简历。这些可选信息暂时没有也没关系。

**用户：**

> 四年，本科。先看互联网公司，薪资暂时不限。我还没整理好简历。

**Agent：**

> 基本信息齐了。我会搜索上海的策略与增长运营岗位，结合岗位职责判断方向是否相关。你还没提供具体项目经历，所以这轮先帮你发现方向相关的机会，暂不判断个人匹配程度。

此时采用 **Discovery Mode（岗位方向发现）**。知道年限和学历，不代表已经掌握足够的个人能力证据。

## 2. 提供经历后，再做有依据的匹配

**用户：**

> 我补充一下：之前负责用户分层和召回，用 SQL 分析数据，也做过 A/B 测试。我有一个召回项目，复购率从18%提升到23%，主要负责策略设计和效果分析。Python 我没提过，先别替我判断。

**Agent：**

> 我会根据你提供的用户分层、召回、SQL 和 A/B 测试经历，逐项对照岗位要求。复购率变化会保留你描述的口径，不扩写为全部由个人贡献。Python 暂记“待确认”，不会因为没写就认定你不会。

此时可进入 **Matching Mode（基于经历证据的匹配）**，对核心要求分别记录“有证据支持／待确认／明确不满足”，并解释原因，不生成匹配百分比。

## 3. 看懂推荐和核验状态

下面只节选三条**虚构岗位**，用于说明展示方式。实际默认展示最多10条，同时提供完整岗位 Excel；推荐数量不是搜索数量。

| 编号 | 公司与岗位（虚构） | 推荐理由 | 招聘核验情况 | 还需确认 | 投递状态 |
|---|---|---|---|---|---|
| J001 | 示例甲公司·用户增长运营 | 职责涉及用户分层、召回和实验分析，与已提供经历相关 | 官网公开招聘，已观察到该岗位的官方申请入口 | 是否有该行业经验 | 未投递 |
| J002 | 示例乙公司·策略运营 | 核心职责涉及经营分析和策略实验，与SQL及A/B测试经历相关 | 第三方线索；未找到官网对应职位，尚未确认当前在招 | Python实际使用情况 | 未投递 |
| J003 | 示例丙公司·增长产品运营 | 涉及增长实验，但产品协作经验仍需补充 | 官网访问受阻，未完成核验 | 与产品、研发协作的项目证据 | 未投递 |

“招聘状态待核实”表示**尚未确认当前是否在招**。它不等于已关闭，也不等于已确认在招。第三方岗位可以保留推荐资格；官网没搜到、访问受阻、明确关闭，会分别说明。404本身不能证明岗位关闭。

实际输出会附真实岗位链接。找到确认相同的官网职位时，会提供官网链接并保留第三方来源记录；仅疑似相同的岗位不会直接合并。发布日期没有可靠证据时留空。

## 4. 只问对选择有帮助的问题

**示例情境：** 一批相关岗位频繁将 Python 列为核心要求，但用户能力尚不明确。

**Agent：**

> 这批岗位中，Python 是反复出现的核心要求，确认后会影响哪些岗位更值得优先看。你的 Python 经验属于实际工作使用、个人项目或学习实践、了解概念，还是暂时不了解？也可以先跳过，保留待确认。

如果只有少数岗位顺带提到某项技术，通常保留“待确认”，不为每个未知项打断对话。几百条结果也不会直接大量过滤：先归纳实际岗位分布，再询问能帮助缩小范围的方向或偏好。用户明确想广泛浏览时，会继续整理展示。

## 5. 用自然语言继续管理

**用户：**

> 优先看看阿里系、字节和飞书、Kimi，其他公司也可以。

**Agent：**

> 已保存为你的本地搜索偏好：优先覆盖这三组，同时扩搜其他相关公司。这个顺序影响搜索覆盖，不会自动提高岗位的个人匹配评价。

**用户：**

> J002不考虑了。J001我已经投了。下次帮我重新核验。

**Agent：**

> J002已记为“不再考虑”，后续不重新推荐；J001已记为“已投递”。重新核验只更新招聘来源与核验记录，保留你的投递状态。

同一岗位保留稳定编号，方便后续追踪。公司拒绝候选人与用户主动不考虑，是不同的投递状态。

## 6. 带走完整结果

实际搜索完成后，提供可下载的 Excel，包含：

| 工作表 | 用途 |
|---|---|
| All Jobs | 全部岗位，包括待核实、不再考虑和已关闭的记录 |
| Recommended | 本轮推荐，默认最多10条 |
| Application Tracker | 投递状态与后续跟进 |
| Verification Log | 来源链接、核验时间、证据与限制 |

Excel 生成依赖运行环境；未成功生成时会明确说明，不把文字表格称为已完成的 Excel。你也可以继续要求针对某份 JD 提供简历优化建议；Skill 不会自动修改原简历或替你投递。
