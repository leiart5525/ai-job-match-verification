# 空白资料首轮自然语言试用

## 原始用户输入

我想找一个工作，你能帮我吗？

## 实际工具调用摘要

1. 读取指定 Skill 的 `SKILL.md`、`references/workflow.md` 和 `references/data-contract.md`。
2. 调用 `jobmatch.py --help` 和 `intake --help` 确认实际命令接口。
3. 创建本场景目录，使用本场景独立的绝对路径 `state.json` 执行 `init`，返回 `{}`。
4. 对该状态执行 `intake`。实际返回 `ready=false`；缺少 `target`、`locations`、`experience_years`、`education`，动作是 `Ask required before formal search`。
5. 尚未调用外部职位搜索；尚未生成候选人经历、岗位、匹配结论或 Excel。仅本场景状态和本记录被写入，未修改交付包。

## 首轮中文回复

可以，我能帮你找真实招聘岗位、核实是否还在招聘，并根据你的经历梳理适合的方向。

开始找之前，请一起告诉我这四项：

1. **想做什么方向**：大致岗位或工作类型就行，不必确定具体职位名称；还没想好也可以说说你喜欢做什么。
2. **想在哪里工作**：城市或地区，也可以明确说不限地点。
3. **工作年限**：应届或没有工作经验可以填 0 年。
4. **最高学历**。

如果方便，也可以补充期望薪资、行业或公司偏好、全职/兼职及远程偏好、技能、项目或工作成果、到岗时间，或者发一份简历。这些都是可选项，不需要上传简历也能开始。

你可以直接按“方向：……；地点：……；年限：……；学历：……”回复。

## 第二轮用户输入

先就增长运营方向吧。

## 第二轮实际工具调用摘要

1. 调用 `ingest --help` 确认参数。
2. 写入本场景的 `intake-growth.json`，仅包含用户明确提供的 `target: 增长运营` 和空职位列表。
3. 对已有 `state.json` 执行 `ingest intake-growth.json`，实际返回 `mode=Discovery`、`jobs=0`。
4. 执行 `intake`，实际返回 `ready=false`，仅缺少 `locations`、`experience_years`、`education`。
5. 未重复询问已提供的方向；未启动外部搜索；未虚构地点、年限、学历或经历。

## 第二轮中文回复

好，方向先定为**增长运营**。开始找岗位前，还需要三项信息：

1. **工作地点**：想在哪个城市或地区？也可以明确说不限地点。
2. **工作年限**：没有工作经验可以填 0 年。
3. **最高学历**。

如果方便，也可以一起说说期望薪资、行业或公司偏好、全职/兼职及远程偏好、到岗时间，以及做过的拉新、转化、留存、用户运营项目或成果；也可以发简历。这些都可选，不填也能继续。

可以直接回复：“地点：……；年限：……；学历：……”。
